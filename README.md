# SCC-PRNet

This repository contains the implementation of SCC-PRNet for hyperspectral
image destriping, including the model, data pipeline, and training and
evaluation workflow.

This project includes adapted components from
[Mamba](https://github.com/state-spaces/mamba) and
[causal-conv1d](https://github.com/Dao-AILab/causal-conv1d). Their original
license and attribution files are retained under `requirements/`.
